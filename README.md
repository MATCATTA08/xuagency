## Modificare il sito

- **Link al negozio:** quando il negozio TikTok Shop è online, apri `index.html`, cerca `const SHOP_URL = "";` e incolla l'indirizzo tra le virgolette. Tutti i pulsanti "Acquista" punteranno lì.
- **Pubblicazione:** GitHub Pages pubblica automaticamente il branch `main` (cartella principale) a ogni commit, di solito entro un minuto.
